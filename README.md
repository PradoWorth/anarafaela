# Studio Ana Rafaela

Site do Studio Ana Rafaela, salão de beleza em Colombo, PR.

## Estrutura

- `index.html`: o site inteiro (página única)
- `img/`: fotos e logos
- `og.jpg`: imagem de compartilhamento em redes sociais
- `robots.txt` e `sitemap.xml`: SEO
- `.htaccess`: HTTPS, redirecionamentos e cache (servidores Apache)
